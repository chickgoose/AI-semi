# a1 Worktree Ownership

The `a1` branch owns the common baseline contract and baseline RTL:

- `docs/spec.md`
- `rtl/common/**`
- `rtl/baseline/**`
- baseline-only smoke checks under `tests/a1/**`

It must not modify improved RTL, the shared verification environment, or the
server/PPA flow owned by the other worktrees.

Current deliverable:

1. [x] Parameterized fixed-priority arbiter.
2. [x] One-entry registered AER transmitter.
3. [x] One-entry elastic AER receiver.
4. [x] Legacy request/ack baseline top.
5. [x] Common ready/valid baseline core and `aer_dut` adapter.
6. [x] Independent event-address payload and source sideband propagation.
7. [x] Legacy and comparison-DUT smoke tests.
8. [x] Fixed-priority starvation characterization.
9. [x] Server Xcelium regression and Genus elaboration sanity check.
10. [x] Shared a3 scoreboard regression under server Xcelium.

Xcelium requires a timescale for every elaborated module. The baseline RTL has
no source-level timing semantics, so server regressions supply the common
simulation setting explicitly:

```sh
xrun -64bit -sv -timescale 1ns/1ps \
  -f rtl/baseline/baseline.f \
  tests/a1/aer_baseline_smoke_tb.sv \
  -top aer_baseline_smoke_tb

xrun -64bit -sv -timescale 1ns/1ps \
  -f rtl/baseline/baseline_dut.f \
  tests/a1/aer_baseline_payload_tb.sv \
  -top aer_baseline_payload_tb

xrun -64bit -sv -timescale 1ns/1ps \
  -f rtl/baseline/baseline_dut.f \
  tests/a1/aer_baseline_starvation_tb.sv \
  -top aer_baseline_starvation_tb
```

Genus elaboration uses an absolute Liberty path because Tcl does not expand
`~` in the `read_libs` argument.
