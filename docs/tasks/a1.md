# a1 Worktree Ownership

The `a1` branch owns the common baseline contract and baseline RTL:

- `docs/spec.md`
- `rtl/common/**`
- `rtl/baseline/**`
- baseline-only smoke checks under `tests/a1/**`

It must not modify improved RTL, the shared verification environment, or the
server/PPA flow owned by the other worktrees.

Current deliverable:

1. Parameterized fixed-priority arbiter.
2. One-entry registered AER transmitter.
3. One-entry elastic AER receiver.
4. Integrated baseline top and file list.
5. Minimal smoke test for interface and backpressure behavior.
