0. 한 줄 요약

우리는 supplied pose를 strict-past causal하게 사용해 sensor event를 world coordinate로
안정화하는 rotation-only MC-WTB를 개발하고 있다. current CAV 기준선은 실제 UZH
NEW108에서 양의 효과가 확인됐고, MID/HIGH motion 효과를 더 높이기 위해 RG3-CAV,
DSPB, SO3-PLL 세 후보를 구현했다. 현재 후보 성능 측정 전 실행 메모리 문제를 해결하는
마지막 단계이며, prediction winner 이후에는 경량 residual feedback과 fail-safe gating을
통합한다. depth/translation/parallax는 8월 28일 제출 범위에서 제외한다.

1. 제출 범위와 문제 정의

이번 제출에서 실제로 구현·검증할 범위:

- rotation CAV+ 핵심 회로
- pan(yaw), tilt(pitch), roll 및 일반 3축 SO(3) pose 입력
- supplied motion/pose parameter를 사용하는 strict-past causal prediction
- 과거 pose residual만 이용하는 경량 feedback
- 급정지·반전·pose 불안정 시 보정 강도를 낮추거나 bypass하는 causal gating
- world-tile aggregation/transport로 연결되는 명확한 시스템 interface
- 교육용 45 nm PDK의 Genus 합성, timing, area, power 및 Innovus P&R

이번 제출에서 해결했다고 주장하지 않을 범위:

- depth 추정
- translation/parallax 보상
- 독립적으로 움직이는 물체의 multi-motion segmentation
- 학습형 feedback 또는 대규모 online training
- 모든 scene/센서에 대한 일반화

교수님 Q&A와의 연결:

- 문제와 핵심 병목을 먼저 정의한다.
- sensor coordinate와 world coordinate 변환을 고려한다.
- 초기 구현에서는 motion parameter가 공급된다고 가정할 수 있다.
- 시나리오 기반으로 기능과 성능을 검증한다.
- 핵심 기능을 먼저 완성한 뒤 시스템 범위를 확장한다.
- 기능 성립 후 timing·area·power와 실제 구현 가능성을 검증한다.

4. 실측할 세 후보

RG3-CAV:

- 최근 세 committed pose로 bounded angular acceleration을 추정
- cadence/residual/direction/magnitude guard가 불안정하면 exact current CAV fallback
- 장점 후보: 가속·감속 구간 예측력
- 위험: second-difference noise 민감도

DSPB:

- current CAV, EWMA, bounded RG3, signed-speed의 네 expert
- 미래 event 결과가 아니라 과거 pose forecast residual만으로 다음 expert를 선택
- 장점 후보: motion regime별 적응
- 위험: 상태·비교기 비용과 regime-change 지연

SO3-PLL:

- 과거 forecast residual을 bounded P/I correction으로 다음 epoch에 반영
- predictor와 residual feedback의 결합에 가장 가까운 후보
- 장점 후보: velocity noise·systematic lag 완화
- 위험: gain/lock/dropout/quantized limit cycle

세 후보는 현재 Python model-only다. fixed-point, predictor RTL, 후보별 Genus/Innovus
결과는 아직 없다.

5. 고정 내부 판정 기준

세 후보는 동일 NEW108, 동일 config, 동일 metric, 동일 8 GiB 제한에서 순차 실행한다.
사전에 고정한 AND gate:

- OVERALL pooled effect > 0
- MID pooled effect > 0
- HIGH pooled effect > 0
- LOW pooled effect >= -0.25%
- 전체 quality-waste가 current CAV보다 악화되지 않음

추가 비교 항목:

- stop/reversal/dropout 안정성
- candidate-use/fallback 비율
- deterministic replay와 receipt 무결성
- 예상 state/operator/latency 비용
- fixed-point와 RTL 변환 위험

모든 후보가 gate를 통과하지 못하면 억지로 winner를 만들지 않고 current CAV 유지 또는
전 후보 STOP으로 판정한다. 이 판정은 다음 RTL 구현 대상을 고르는 내부 engineering
결정이며, 공식 대회 winner나 일반화 증거가 아니다.

6. 실제 실행 문제와 현재 수정 상태

1차 actual RG3 8 GiB acceptance 결과:

- elapsed: 42:03.27
- maximum RSS: 8,260,256 KiB
- exit: fail-closed MemoryError
- failure stage: PRODUCTION_ADAPTER
- screen started: false
- score computed: false
- labels accessed: false
- verified failure receipt SHA-256:
  8d42143b0a7c8942c749512bc8422a7cabd86559e947c1fec427204423d386f2

이 실패는 후보 성능 실패가 아니다. score와 label을 보기 전에 종료됐으며 원인은 다음
Python object lifetime 중첩이었다.

- compact baseline
- candidate native output graph
- canonical JSON 전체 복사본

완료된 2차 수정 범위:

- production과 verification을 별도 process로 격리
- parent preflight baseline을 production 전에 해제
- canonical hash/output serialization을 streaming화
- worker source, Python runtime, execution context, production/verification response digest를
  receipt/verifier까지 결속
- phase timeout을 600초에서 고정 3600초로 수정
- timeout·kill/wait·append-only 관련 집중 테스트 PASS

새로 발견해 현재 수정 중인 잔여 위험:

- parent에서 full native parse와 projection graph를 만든 뒤 같은 process에서 screen
  baseline을 재구축하면 allocator high-water가 겹칠 수 있음

현재 구현 중인 해결책:

- projection을 별도 child process로 실행
- projection child가 완전히 종료된 뒤 screen을 별도 child process로 실행
- screen child만 label에 접근
- parent는 compact identity와 digest만 유지
- 기존 projection/screen artifact byte는 변경하지 않음
- 각 child의 worker/runtime/input/output digest를 final receipt/verifier에 결속

현재 직접 fixture 증거:

- production/verification 기반 scoped campaign tests: PASS
- projection과 screen이 서로 다른 PID에서 순차 실행: PASS
- projection process 종료 후 screen process 시작: PASS
- projection response labels_accessed=false: PASS
- screen response labels_accessed=true: PASS
- 기존 projection·screen-output·executable artifact exact-byte equality: PASS
- 중간 artifact mutation 시 screen result 생성 거부: PASS
- parent rich native/projection object lifetime release: PASS

단, 위 process-isolation 수정은 아직 전체 suite·독립 red-team·fresh clone 전이므로
SCOPED_IMPLEMENTATION_IN_PROGRESS다. 실제 NEW108 8 GiB PASS로 쓰면 안 된다.

8. 혁신성의 정확한 경계

event warping, constant velocity/acceleration, model bank, PLL/feedback은 각각 알려진
기술이다. 이를 단독 혁신으로 주장하지 않는다.

현재 차별화 가설은 다음을 묶은 hardware/system contract다.

- supplied-pose authority
- strict-past causal eligibility
- equal-edge/equal-timestamp atomicity
- immutable past decision
- exact-once event semantics와 exact fallback
- event outcome을 보지 않는 pose-residual prediction/feedback
- fail-safe causal gating
- world-tile aggregation/transport interface
- latency/state/PPA를 전부 charge하는 45 nm complete-endpoint co-design

현재 claim은 SYSTEM_CONTRACT_DIFFERENTIATION_HYPOTHESIS_ONLY다. broad novelty 또는
특허성을 확립했다고 주장하지 않는다.
