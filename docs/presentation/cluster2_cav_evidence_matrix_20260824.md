## 1차 발표 위치

- 중심 결과: pinned Cluster2 native AER의 sealed Xcelium RTL simulation observation.
- 보조 결과: official UZH identity를 native outcome과 observational software join한 뒤 수행한 causal-CAV/world functional replay.
- 안전한 결론: **event-identity 수준의 software functional extension feasibility를 실제 데이터로 확인했다.**
- 금지 결론: wire-level 호환성 보장, CAV RTL 완성, latency-quality 개선, 일반적 scalability, release-bound native/CAV PPA 완료.

발표 슬라이드에서 `PASS`만 떼어 쓰지 말고 이 표의 판정 문자열과 제한을 함께 표시한다.
