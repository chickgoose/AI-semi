1. 현재 목표
============

교육용 GPDK045에서 주최 측이 허용하는 셀과 clock 구조만으로 16-source
pending/accept부터 retire까지의 완전한 AER digital endpoint를 구현한다.

A2는 aggregate-weighted 성능 primary, A3는 exact scalar-prefix 의미
fallback으로 둔다. 동일 조건의 팀 canonical synthetic traffic과 제공/공개
traffic에서 다음을 비교한다.

  - accepted-event exact-once
  - source overrun
  - throughput
  - occurrence-to-accept 및 accept-to-retire latency
  - post-route timing/area
  - mapped vectorless power

Known-motion world-to-sensor 좌표 변환은 endpoint PPA 밖의 system demo로
분리한다. 최종 후보 선정은 digital recommendation만으로 하지 않으며,
physical, power, PDK, CDC/RDC 및 evidence authority gate가 모두 닫힌 뒤에
수행한다.


2. 현재 한 줄 판정
==================

A2는 actual-RTL native digital campaign의 aggregate 성능 primary지만,
동일 6.5 ns GPDK045 post-route screening에서 setup을 닫지 못했다. A3는
exact-prefix 의미를 유지하면서 최종 setup/hold를 모두 닫고 실제 artifact
qualification의 diagnostic checks를 완료했다. 그러나 constraint는
TEAM_PLACEHOLDER_SCREENING_ONLY이고 producer authentication/cohort/final
release gate가 없으므로 현재 final candidate는 NONE, selection/release는
HOLD다.


3. 핵심 architecture
====================

현재 active endpoint 경계:

  16-source source_pending_i/source_accept_o
    -> A2 또는 A3 scheduler
    -> admission 및 charged buffering
    -> registered single-edge TX
    -> 9-wire {link_valid, addr0[3:0], addr1[3:0]}
    -> registered single-edge RX
    -> ordered two-lane retirement
    -> drain/error observation

Clock/reset:

  - primary clock: clk_i
  - active edge: posedge only
  - reset: synchronous active-high rst_i
  - generated/gated/forwarded/negedge clock 없음
  - DDR/multi-edge/vendor-specific primitive 없음

9-wire cell이 표현하는 semantic record:

  - idle: 1개
  - singleton: 16개
  - distinct ordered pair: 16 x 15 = 240개
  - 총 257개, ceil(log2(257)) = 9

9-wire는 전체 chip I/O 폭이 아니라 endpoint 내부 physical-functional
event-cell link 폭이다.

Endpoint PPA 포함:

  - scheduler policy/state
  - admission control
  - charged buffer
  - link launch/TX/RX
  - retirement
  - drain/error logic

Endpoint PPA 제외:

  - event generation before pending
  - testbench/scoreboard/retry storage
  - pads/package/channel
  - coordinate transform
  - motion estimation/visualization


4. A2와 A3
===========

A2:

  - persistent interleaved weighted round-robin
  - row weight [1,5,5,1]
  - sparse fallback to another eligible row
  - scheduler opportunity당 최대 2 event accept
  - aggregate throughput과 source-overrun 감소가 목표
  - exact scalar-prefix를 보장하지 않음
  - debt/catch-up semantics가 아님

A3:

  - held pending snapshot에 canonical scalar selector를 두 번 적용
  - exact two-selection prefix 보장
  - exact-prefix가 요구될 때의 semantic fallback
  - 또는 A2-specific named gate가 실패하고 A3가 그 gate를 독립적으로
    통과한 경우에만 활성화 가능
  - shared PDK/interface/CDC/evidence failure는 A3 선택 사유가 아님
  - 2026-08-19 timing 개선에서 scalar grant를 native 16-bit onehot으로
    유지하여 binary address 재인코딩/재디코딩 경로를 제거함
  - 72 lockstep runs, 171,634 vectors에서 기존 의미와 일치했으며,
    4-state X 동치/formal proof는 별도 HOLD 항목임

6. 혁신성으로 주장 가능한 범위
===============================

  1) aggregate 성능 A2와 exact semantic A3를 명시적으로 분리했다.

  2) generated = source_overrun + accepted와, clean drain 뒤
     accepted = retired를 별도로 검증한다. Source overrun은 capacity
     loss이고 accepted-event 누락/중복/변조/reorder는 correctness 실패다.

  3) scheduler core-only가 아니라 buffer, TX/RX, retire, drain/error까지
     포함한 complete endpoint를 같은 경계에서 비교한다.

  4) GPDK045 적용 불확실성이 큰 DDR/multi-edge 대신 single-posedge
     standard-cell 구조를 current release 후보로 고정했다.

  5) 257개 atomic ordered record를 9-wire cell에 표현한다.

  6) digital recommendation, policy eligibility, authenticated final selection,
     release를 서로 다른 단계로 분리한 fail-closed evidence model을 쓴다.

  7) caller JSON, historical P6 evidence, 임의 scalar score 또는 shared
     failure로 winner가 생기지 않도록 막는다.

문헌/특허 선행조사가 끝나지 않았으므로 world-first, 최초 알고리즘,
특허성이 입증됐다는 표현은 사용하지 않는다.

9. Digital-to-server compatibility 정책
========================================

디지털 simulation PASS만으로 server-ready라고 판정하지 않는다.

  RTL_FUNCTION_PASS
    -> LOCAL_RTL_PHYSICAL_COMPATIBILITY_PASS
    -> SERVER_GENUS_SMOKE_PASS
    -> SERVER_PNR_READY
    -> PHYSICAL_EVIDENCE_PASS

이번 호환성 수정에서 적용한 내용:

  - A2/A3 실제 RTL과 endpoint/vectorless contract의 마지막 출력 순서를
    protocol_error_o, drain_idle_o로 통일

  - A2/A3 exact filelist와 six-module inventory 검사

  - Genus read_hdl을 정확히 다음 형태로 고정
      read_hdl -sv -define SYNTHESIS -f <exact filelist>

  - missing/extra/reordered/direction/width port mutation을 회귀로 차단

  - endpoint physical contract와 vectorless contract boundary가 동일한지
    교차 검사
